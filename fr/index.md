Ce site est un guide pour débutants du jeu vidéo *Minecraft*. De la fabrication à *l’End*, découvrez les bases de Minecraft et apprenez comment survivre dans un jeu de survie hostile&nbsp;!

Minecraft est un jeu vidéo de type bac à sable sorti en 2011 et développé par Mojang. C’est un jeu en 3D reconnaissable par son apparence « cubique », puisque tout y est constitué de blocs ou de formes carrées.

Les deux principaux modes de jeu sont le mode Survie et le mode Créatif.

## Mode Créatif
Le mode **Créatif** vous permet d’accéder à toutes les ressources de manière infinie depuis votre inventaire et de faire absolument tout ce que vous voulez. Il est généralement utilisé par les joueurs pour construire des structures impressionnantes.

## Mode Survie
<p align="center">
  <img src="../img/survival.png" width="700" height="368">
</p>

Le mode **Survie** vous permet de jouer seul, tandis que des créatures hostiles tenteront de vous tuer pendant que vous essayez de survivre en récoltant des ressources avant d’affronter le boss final du jeu. Dans ce mode, vous disposez d’un certain nombre de cœurs représentant votre santé, qui peut diminuer si vous subissez des dégâts ou êtes empoisonné. Vous devez également satisfaire votre faim pour régénérer votre santé.

Comme le titre du jeu l’indique, Minecraft repose sur le minage et la fabrication. Le seul véritable « objectif scénaristique » est de vaincre l’Ender Dragon, ~~si vous osez.~~

## Vocabulaire de base

#### Mob : Un mob est une créature. Cela peut être un animal (vache, cochon) ou un monstre (zombie, creeper).

#### Biome : Un biome est un environnement défini. Par exemple, un biome désertique est un désert.

#### Fabriquer (Craft) : Fabriquer consiste à créer un objet en utilisant différents items et ressources, généralement via une table de fabrication. Vous pouvez par exemple fabriquer des outils comme des haches ou des pioches.

#### Miner : Miner consiste à récolter des ressources à partir de minerais à l’aide d’une pioche. Par exemple, les diamants et le charbon peuvent être minés.

#### Butin (Loot) : Le butin est ce qu’un mob laisse tomber lorsqu’il est tué ou ce que l’on peut trouver dans un coffre.
